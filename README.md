# Nomad Codelabs Homebrew tap

```bash
brew install --cask yellowsnowagency/tap/loper
```

If Homebrew says the tap isn't trusted yet, run `brew trust yellowsnowagency/tap` once and install again.

[Loper](https://loperedit.com/) is a small, fast editor and viewer for code, config, logs, subtitles and PDFs. Apple Silicon only. Loper updates itself, so `brew upgrade` leaves it alone unless you pass `--greedy`.
